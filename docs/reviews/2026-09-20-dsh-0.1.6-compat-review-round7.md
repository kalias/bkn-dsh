未取得：Windows job 的测试计数与 symlink skip 数（run 整体仍为 queued，gh 在 run 结束前无法取日志）。

### 4.2 macos-13 job 无法调度 [已验证现象；原因为推断]

三次 run 的 macos-13 job 均持续 queued（最长已超 1 小时），run 永不结束。推断原因：GitHub 已下线 macos-13 托管 runner。影响：

- darwin-x64 产物永远不会产出；
- 若推 `openbkn-dsh-runtime-v*` tag，`publish` job `needs: build`，将永久阻塞，Release 发不出来；
- run 不结束导致其余 job 日志无法用 gh 拉取。

### 4.3 round6 之后两个提交未经审核 [已验证]

- `f71c1d5`：`package-bundle.mjs` 审计仅在主模块执行且 win32 用 `pnpm.cmd`；`windowsZipArgs`/profile CLI 测试改用 `resolve()`；exec-bit 断言限 POSIX；`sourceMappings` 同时尝试 realpath 与原始源根（覆盖 8.3 短名）；`.bin` 镜像测试失配时输出完整替换列表。
- `47c03ab`：win32 下以 shell 启动 pnpm；`mirrorsTarget` 改为大小写不敏感、容忍混合分隔符的规范化键匹配。

**`47c03ab` 修改了 `runtime/bundle-portability.mjs` 的 `mirrorsTarget`，属于发布产物组装路径**，不只是测试。审核重点：规范化键在 POSIX（大小写敏感文件系统）上是否会把本应区分的路径误判为同一镜像根。
